# バトスピ価格比較

バトルスピリッツのカードを、複数の通販ショップでまとめて検索するページです。

**▶ 開く：https://kappaaa34.github.io/batospi-search/**

スマホ（iPhone）でもそのまま使えます。Safari の「共有 → ホーム画面に追加」をすると、アプリのように開けます。

## 使い方

1. カード名を入れて「検索」を押すと、選んだショップの検索結果が開きます。
2. 検索欄の下のショップ名を押すと、「検索」で開くかどうかを切り替えられます（色付き＝開く）。
3. 「タブの開き方」で、ショップごとにタブを開くか、1つのタブで切り替えるかを選べます。

- 英字は自動で半角の大文字にそろえて検索します（例：`ノヴァ　xv` → `ノヴァ XV`）。大文字・小文字を区別するショップがあるためです。
- 検索履歴は、検索してから2週間で自動的に消えます。
- 送料・店舗受取の一覧は、ショップ設定から書き換えられます。
- 「Xのバトスピ投稿」のボタンを押すと、ドラスタ秋葉原（バトスピの語を含むものだけ）と CARDWINGS 秋葉原駅前店のバトスピアカウントの X 投稿が、Yahoo!リアルタイム検索で開きます（ログイン不要）。

## 登録しているショップ

ホビステ / ドラスタ / ティアワン / バトスキ / 遊々亭 / カードラッシュ / フルアヘッド / トレカ侍 / カードラボ / BIGWEB / 駿河屋 / メルカリ / magi

最初から入っている送料・店舗受取は、2026年10月に各ショップのご利用ガイドで調べた内容です。変わることがあるので、注文前にショップでも確かめてください。

## 注意

- 検索履歴とショップ設定は、使っているブラウザの中にだけ保存されます。PC とスマホ、Safari と Chrome では別々です。
- 一度に複数のタブを開くと、ブラウザに止められることがあります。そのときは、ブラウザでこのサイトのポップアップを許可するか、「1つのタブで切り替え」を使ってください。
